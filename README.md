# 砚时考钟（yanshi-clock）V1.1.7

古风考场虚拟时钟微信小程序 · 纯前端离线 · 个人主体免费版

面向模拟考试、备考自习和时间管理场景，支持自定义考试名称与起止时间、电子钟与古风挂钟切换、白噪音、分段提醒、结束铃声、考试进度恢复和本地历史统计。项目无需服务器或用户登录，导入微信开发者工具即可运行。

## 打开方式

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本目录 `yanshi-clock`
3. 确认 `project.config.json` 中的 `appid` 属于你的小程序（否则替换为自己的 AppID）
4. 点击「编译」，再用「预览」做真机音频与震动测试
5. 确认无误后点击「上传」，版本号填 `1.1.7`

## 功能概览

- 虚拟考试起止时间计时（非真实倒计时）
- 电子考钟 / Canvas 木质挂钟双模式
- 三种表盘：十二时辰 / 数字 / 时辰+四正位
- 考试模板、提醒（弹窗/震动/音效）、主题、学习统计
- 考试结束铃声可单独开关，与剩余时间提醒分开管理
- 进行中/暂停中的考试自动存档，进程重启后恢复
- 最近 50 场模考历史记录查看
- 7 个内置音频（3 个提醒音 + 4 个环境音），无网络请求
- 本地 `wx.storage` 持久化，无服务器、无登录

## 目录

app.js / app.json / app.wxss

## 音频资源

音频已打包在 `assets/audio/`，导入后可直接播放。环境音为 24kbps、短音效为 32kbps 单声道 MP3，全部图片和音频合计低于 200KB。细雨书窗来自 Wikimedia Commons 的 CC0 轻雨实录，其余音频由本项目程序化生成，授权说明见 `assets/audio/SOURCE.md`。

需要重新生成时执行：

```bash
node scripts/generate-audio.js
```

完整代码包低于当前项目文档中的 2 MB 主包目标。

## 数据与隐私

- 考试配置、进度、偏好和统计只保存在用户本机
- 不请求登录、手机号、位置、相册或服务器权限
- 意见反馈内容仅在用户点击提交后写入剪贴板，不会自动上传

## 上传前检查

```bash
node scripts/smoke-check.js
```

然后在微信开发者工具中检查：

1. 时钟页开始、暂停、恢复和重置正常
2. 切换电子钟/挂钟、全屏、主题和表盘正常
3. 提醒音试听、白噪音播放/切换/音量正常
4. 在真机上确认震动和屏幕常亮
5. 基础库使用项目内的 `3.17.0` 或一个稳定新版本
